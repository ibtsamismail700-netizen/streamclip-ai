Thumbnail Creator / Redesigner

Upload a thumbnail — AI analyses it, then generates completely different versions with the same text, plus a prompt chat box to create thumbnails from scratch.

Redesign an existing thumbnail

Or create from a prompt

Chat with the AI: describe the thumbnail you want. It generates an image with your key, or gives you a build-ready concept.

How this tool works

1
Upload the thumbnail you want to improve (or skip the upload to start fresh).
2
Tap "Analyse thumbnail" — the AI reads the image: its topic, exact text, colours, subject and weak points, and suggests redesign directions.
3
Type the text that must stay the same, then tap "Generate different versions".
4
You get 4 versions — Bold Yellow, Dark Neon, Red Alert and Clean Mint — each a different layout, background and style, all with your exact text. Download any of them.
5
Or use the prompt chat box to generate a thumbnail from a written idea.

What you need

  • Your free Gemini key added in Settings (one minute, free)
  • A thumbnail image (for analysis and redesign)
  • The exact text for the new versions

What you get

  • A designer-level analysis of your thumbnail
  • 4 ready-to-download versions (1280×720) that look completely different
  • AI images or concepts from your own prompts

Tips

  • Keep text to 3–5 words — it must be readable at phone size.
  • One face, one emotion, one idea per thumbnail wins clicks.
  • Download two versions and A/B test them on YouTube.

FAQ

Do the new versions keep my text exactly?

Yes — the version maker draws the exact text you typed on every version. Only the design changes.

Can the prompt box really generate an image?

Yes, when your Gemini key has access to Google's image model, the image is generated and shown here. If not, the AI returns a detailed concept you can build with the version maker.
